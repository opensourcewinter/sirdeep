## 💻 Live Command Demonstration Script

You can copy-paste these commands while recording your demo to show live interactivity:

### 1. Starting the Engine
```bash
# Production launch
docker compose up -d

# Check live logs
docker compose logs -f
```

### 2. Discord Chat Demonstrations
```text
# Chat with SirDeep
@SirDeep What are the tradeoffs between WAL mode and rollback journal in SQLite?

# Switch Radio Station
/radio station station:synthwave

# Generate Glassmorphic Rank Card
/rank

# Trigger an Architecture Debate
/debate post topic:"Monolith vs Microservices for high-traffic startups"
```

## 📹 Recording Recommendations

1. **Resolution**: 1920x1080 (1080p, 60fps) or 4K.
2. **Discord Theme**: Dark Mode or Midnight.
3. **Font**: JetBrains Mono or Inter.
4. **Tools**: OBS Studio, Loom, or Screen Studio.
5. **Export Format**: Web-optimized `.mp4` or 15-second high-framerate `.gif` for the top of GitHub `README.md`.
